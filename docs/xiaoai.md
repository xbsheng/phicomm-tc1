# 接入小爱同学（巴法云）

可选链路。**它是"锦上添花的语音入口"，不是主控**：巴法云停服或小米收紧通道，只影响语音，本地 HA 照常工作。

## 1. 为什么必须过云

小爱是云语音助手，只认注册在小米 IoT 云里的设备；米家**没有**"局域网直连第三方设备"的通道。非米家设备接小爱只有三条路：

| 路子 | 个人可行性 |
|---|---|
| 米家官方认证接入（企业资质 + 模组认证） | 做不到 |
| 小爱技能开放平台自定义技能（企业开发者 + 公网 HTTPS 回调） | 基本做不到 |
| **云云对接**：米家「其他平台设备」绑定第三方云 | ✅ 唯一现实路径 |

巴法云属于第三类。它**不是小米的产品**，是独立第三方 IoT 云（域名 2017 年注册，服务在腾讯云），通过米家的第三方平台通道把设备同步过去。

## 2. 固件要求

- 巴法云直连自 **v0.9.18** 起支持
- **v0.9.27 的网页没有巴法云设置项**（前端资源里无相关控件），只能用 HTTP API 写
- v1.0.0 起网页有对应设置页

## 3. 建主题（巴法云控制台）

MQTT 云 → 新建主题。命名规则：

- 只能**英文字母 + 数字**（下划线不被接受）
- 长度 ≤63 字节
- **最后三位决定设备类型**：`001` 插座、`002` 灯泡、`003` 风扇、`004` 传感器、`005` 空调、`006` 开关、`009` 窗帘

六路插孔要都是"插座"，所以每个主题都以 `001` 结尾，例如：

```
tc101001
tc102001
tc103001
tc104001
tc105001
tc106001
```

然后到「连接密钥」页拿两个值：**AppID** 和 **SecretKey**（注意：是连接密钥，不是登录密码）。

## 4. 写进设备

固件用的是 MQTT 用户名/密码方式：

```
clientID  = phicomm-tc1-<mac>-bemfa     （固定）
username  = AppID
password  = SecretKey
broker    = bemfa.com:9501
```

设备侧写入（0.9.27 的 HTTP 是 JSON，Basic 认证 `admin:<网页密码>`）：

```bash
curl --noproxy '*' -u 'admin:<WEB_PASS>' \
  -H 'Content-Type: application/json' \
  -d '{"action":"config.set","params":{"section":"bemfa","values":{
        "enabled":true,
        "app_id":"<APPID>",
        "secret_key":"<SECRET>",
        "topics":["tc101001","tc102001","tc103001","tc104001","tc105001","tc106001"]}},
      "request_id":"set-bemfa"}' \
  http://<PLUG_IP>/api/v1/command
```

回读状态：

```bash
curl --noproxy '*' -u 'admin:<WEB_PASS>' http://<PLUG_IP>/api/v1/status | \
  python3 -c 'import json,sys;d=json.load(sys.stdin)["data"];[print(k,d.get(k)) for k in
  ["bemfa_enabled","bemfa_connected","bemfa_status","bemfa_errors","bemfa_last_error"]]'
```

期望 `bemfa_connected = True`、`bemfa_status = ready`。

| 结果 | 含义 |
|---|---|
| `auth_failed` / `bemfa_last_error = 5` | AppID 或 SecretKey 错（把私钥当 AppID 填是最常见原因） |
| 一直 `connecting` | 设备出不了外网，或 `bemfa.com:9501` 被拦 |
| `ready` 但主题无消息 | 控制台里主题名与设备填写的不一致，或主题未创建 |

## 5. 米家里绑定

米家 App → **我的 → 其他平台设备 → 添加 → 找到「巴法」→ 登录巴法云账号** → 「同步设备」。

绑定成功后，6 个主题会以"插座"身份出现，但：

- 第三方设备**不支持设置家庭和房间**，不会进按房间分类的列表
- 只在这两处可见：「我的 → 其他平台设备 → 巴法」、首页「全部设备」列表最底部

## 6. 改名字（必须做，否则语音分不清）

默认 6 个设备全叫"插座"，小爱无法区分。名字在**巴法云**改，不在米家：

1. 巴法云控制台 → 主题卡片 → **更多设置 → 昵称** → 改成"书桌灯""路由器"之类
2. 米家侧名字**不会自动跟随**：米的云云对接只在绑定那一刻取快照
3. 让名字生效：**解绑巴法 → 重新绑定 → 同步设备**（最可靠），或直接点米家里的设备看有没有重命名入口

改成之后：

```
小爱同学，打开书桌灯
小爱同学，关闭路由器
```

## 7. 验证双向

巴法云控制台主题卡片就是最好的测试台：

| 看什么 | 期望 |
|---|---|
| 订阅者 | **在线**（设备已订阅该主题） |
| 消息 | `on` / `off`（设备轮询上报当前状态） |
| 输入框发 `off` / `on` | 对应那一路立即动作（下行链路） |

## 8. 限制与风险

- `001` 类型只支持开/关，没有功率、没有定时（那些走本地 HA）
- 六路 = 六个独立设备
- **公网明文**：`bemfa.com:9501` 未启用 TLS，开关指令与连接凭据在公网不加密
- 依赖第三方云与小米的第三方通道政策，随时可能变化（巴法云文档里"天猫精灵"已下线就是先例）
- **不要把关键负载（路由器、NAS）只挂在这条链路上**
- 密钥一旦外泄（截图、聊天、仓库）就去控制台**重置密钥**，再按第 4 步写一次
