# 首次启动、配网与升级

刷机成功后设备跑的是过渡包 **0.9.6**，只用于迁移。这一页把设备变成能长期用的状态。

## 1. 连上新的配置热点

刷机完成后会出现**开放**热点：

```
TC1_A1-AP-<MAC 后六位大写>        例：TC1_A1-AP-638B11
```

连上后打开 <http://192.168.0.1/>，进入社区固件网页。

> 这个热点只在**未配置 Wi-Fi** 时出现；一旦联网成功它就会关闭，之后用局域网 IP 访问。

## 2. 先把密码设上

过渡包出厂时 `web_password_set = false`，意味着局域网内任何人都能控制这六路。**第一件事设网页密码**（网页设置 → 网页密码）。

设置后所有 `/api/v1/*` 都要认证：

```bash
curl --noproxy '*' -u 'admin:<WEB_PASS>' http://<PLUG_IP>/api/v1/status
```

用户名固定 `admin`，密码就是网页密码。

## 3. 升级到签名稳定版

0.9.6 是迁移快照，必须升级。选择与设备型号匹配的**签名包**：

```bash
cd ~/tc1-flash
v=v0.9.27
curl -LO https://phicomm-io.github.io/releases/$v/phicomm_tc1_a1.ota.bin.signed
curl -o SHA256SUMS https://phicomm-io.github.io/releases/$v/SHA256SUMS
shasum -a 256 phicomm_tc1_a1.ota.bin.signed
grep tc1 SHA256SUMS
```

网页 → 固件更新 → 上传 `.ota.bin.signed` → 等自动重启。要求：

- 用**签名包**（`.ota.bin.signed`），不是 `.all.bin`（那是 J-Link 整片镜像）也不是 `.raw`
- 全程保持供电，升级中不要断电
- 重启后确认网页里的版本号已更新

> 升级后网页可能多出巴法云等设置项；0.9.27 还没有巴法云 UI，见 [xiaoai.md](xiaoai.md)。

## 4. 固定 IP（必做）

固件的 STA 模式是 **DHCP 客户端，不支持静态 IP**（源码 `user_wifi.c` 写死 `DHCP_Client`）。所以"固定 IP"只能在路由器上做：

**DHCP 地址保留 / 静态地址分配**，绑定设备 MAC：

```
MAC = 设备 ID（12 位十六进制，如 A1B2C3D4E5F6 → A1:B2:C3:D4:E5:F6）
IP  = 现在拿到的地址，保持一致
```

不做的后果：路由器恢复出厂、换路由器、地址池变化后 IP 会变，书签和集成配置都会失效。DHCP 租约通常能跨路由器重启保留，但**没有保证**。

## 5. 换到家里的正式 Wi-Fi

如果刷机时用的是临时开放热点 `PHICOMM_OTA_AP`，务必先把插排切到家里正式的 2.4 GHz Wi-Fi（网页 → Wi-Fi 扫描 → 选 SSID → 填密码 → 保存 → 等它重连），**再**去关掉那个开放热点。

否则：热点一关，插排掉线，只能重新进入配网流程。

## 6. 恢复与找回

| 情况 | 做法 |
|---|---|
| 找不到 IP | 路由器客户端列表按 MAC 查；或按住配网键 5~10 秒重置网络，重开 `TC1_A1-AP-xxxxxx` |
| 忘记网页密码 | 按住配网键 ≥10 秒恢复出厂，重新配网 |
| 网页可访问但功能异常 | 网页本地上传签名包重刷 |
| 设备起不来 | 需要拆机 + J-Link（不在本仓库范围） |

恢复出厂会清空用户设置（六路默认全开），需要重新配网。
